### 🔁 Spaced Repetition System (SR)

The SR system uses a modified SM-2 algorithm to optimize learning:

#### How It Works:
- **Again** (A) - 1 minute - Card is forgotten
- **Hard** (H) - 30 minutes - Some difficulty
- **Good** (G) - 4 days - Correct with some hesitation
- **Easy** (E) - 9 days - Perfect recall
- **Mastered** (M) - 30 days - Completely mastered


#### SR Features:

- **Not Mastered only** - Exclude mastered cards from SR session
- **Session tracking** - Shows remaining cards
- **Progress indicator** - Visual feedback
- **Keyboard shortcuts** - A, H, G, E, M

#### SR Statistics:

- Shows **X due** on the SR button
- Tracks review history for each card
- Automatically schedules next review

### 📝 Exercise Format

Write exercises using `[[answer]]` syntax:

```
Fill in the blanks:
15. Ich habe [[einen]] Hund.
16. Sie trinkt [[die]] Milch.
17. Wir gehen in [[das]] Kino.
```

## Tips & Best Practices

### 🎯 Effective Learning

18. **Start with A1 stories** - Build foundational vocabulary
19. **Use Spaced Repetition daily** - Consistent review is key
20. **Create themed lists** - Organize by topics (Food, Travel, etc.)
21. **Practice with sentences** - Learn words in context
22. **Use both modes** - Grid for browsing, Focus for deep study

### 📈 Progress Tracking

- **Mastery percentage** shows your progress for each list
    
- **SR statistics** indicate which words need review
    
- **Progress bar** visual overview of your learning journey
    

### 💡 Advanced Tips

23. **Batch add words** from stories to create themed lists
24. **Use Dark Mode** for reduced eye strain during long sessions
25. **Export your lists** regularly as a backup
26. **Import from text** using the format: `German :: English`
27. **Add sentences** with format: `German ((sentence)) :: English ((translation))`

### 🔄 Syncing Data

- **Cloud Sync** - Upload/download your data (personal use)
    
- **Export JSON** - Backup your entire collection
    
- **Import JSON** - Restore from backup
    

### 📱 Mobile Usage

- **3-finger tap** in Vocabulary Tool → Focus Mode
    
- **Swipe selection** for words
    
- **Touch-optimized controls** on all buttons
    
- **Responsive layout** adapts to screen size
